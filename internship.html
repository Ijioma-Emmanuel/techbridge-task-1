30-Day Practical Internship

TechBridge Internship Journey

TechBridge provides a structured 30-day practical internship consisting of eight hands-on tasks. Throughout the internship, you'll progressively develop your web development skills by completing practical projects, starting from building the first version of the TechBridge homepage and progressing through different website experiences and interactive systems, until you create a complete TechBridge internship platform. Each task is designed to help you apply what you've learned, improve your technical abilities, and gain practical experience in building real-world web projects.

Explore the 8 Tasks
1 Day 1

Build the TechBridge Homepage

Read More
Ongoing Difficulty: Beginner

In this task, you'll create the first version of the TechBridge website using HTML and CSS. The project involves developing a homepage that introduces TechBridge and presents its information in a clear and organised manner. You'll work on structuring the different sections of the page, arranging content, and applying basic styling to create a professional website. This task introduces you to the fundamentals of building web pages and provides the foundation for the other sections of the TechBridge platform.

2 Day 4

Build the TechBridge Programs Experience

Read More
Ongoing Difficulty: Beginner → Intermediate

In this task, you'll create a Programs experience that presents the available learning programs offered by TechBridge. The goal is to organise and display the programs in a way that makes it easy for visitors to understand what each program offers. You'll focus on presenting program information clearly, arranging content into appropriate sections, and maintaining a consistent design with the existing TechBridge homepage. This task builds on your previous experience with HTML and CSS while helping you develop a more organised and informative website experience.

3 Day 8

Build the Internship Tasks Experience

Read More
Ongoing Difficulty: Beginner → Intermediate

In this task, you'll design and develop an interface that presents all eight tasks in the TechBridge internship. The page should provide visitors with a clear understanding of what the internship involves, the tasks they are expected to complete, and when each task is introduced. You'll organise the task information into an easy-to-navigate layout, providing descriptions that explain what each task is about. The goal is to create an experience that helps new interns understand the entire internship journey and what is expected of them throughout the program.

4 Day 11

Build an Interactive Task Tracker

Read More
Coming Soon Difficulty: Intermediate

In this task, you'll use JavaScript to make the internship task experience interactive and allow interns to track their progress. The task involves introducing functionality that enables users to monitor the tasks they have completed and keep track of their progress throughout the internship. Rather than simply displaying task information, you'll develop an interactive experience that responds to user actions and makes it easier for interns to follow their learning journey.

5 Day 15

Build the Intern Registration Experience

Read More
Coming Soon Difficulty: Intermediate

In this task, you'll create a professional registration and onboarding interface for TechBridge interns. The experience should provide a clear and organised way for prospective interns to begin their registration process. You'll focus on presenting the registration interface in a user-friendly manner, arranging the necessary registration elements and ensuring that the process is easy to understand and navigate. The aim is to create a professional entry point through which individuals can begin their TechBridge internship experience.

6 Day 19

Build the Task Submission System

Read More
Coming Soon Difficulty: Intermediate

This task involves creating an interface through which interns can prepare and submit their completed task work. You'll develop a structured submission experience that gives interns a dedicated place to present their work for review. The interface should make the submission process understandable and straightforward, allowing users to identify where and how to submit their completed tasks. This adds another important component to the TechBridge platform by providing a dedicated experience for handling internship submissions.

7 Day 22

Build the Intern Dashboard

Read More
Coming Soon Difficulty: Intermediate → Advanced Beginner

In this task, you'll create a dashboard that allows interns to view their profile, internship progress, assigned tasks, and submissions. The dashboard should bring these important details together in one organised interface, giving interns a central place to access information about their activities and progress. You'll focus on arranging the different information in a clear and understandable manner, creating an interface that makes it easier for interns to manage and follow their participation in the TechBridge internship.

8 Day 26

Build the Complete TechBridge Internship Platform

Read More
Coming Soon Difficulty: Intermediate → Advanced Beginner

This is the final task of the internship. You'll bring together the different components developed throughout the previous tasks to create a complete TechBridge internship platform. This involves combining the homepage, Programs experience, Internship Tasks experience, interactive task tracker, registration experience, task submission system, and intern dashboard into one connected platform. The objective is to bring the individual projects together into a unified website that presents the complete TechBridge internship experience.
